# Nutrix-AI

AI Nutrition Planner and Health Recommendation System

## About
Nutrix-AI is a web-based project designed to help users plan meals and get nutrition recommendations.

## Features
- User Registration and Login
- Nutrition Information
- Meal Planner
- Weekly Meal Planner
- Health Recommendations

## Technologies Used
- Python
- Flask
- HTML
- CSS
- JavaScript
- SQLite

## How to Run
1. Install the required packages using `pip install -r requirements.txt`.
2. Run `python app.py`.
3. Open `http://127.0.0.1:5000` in your browser.

## Project Purpose
To help users organize meals and understand basic nutrition information.
